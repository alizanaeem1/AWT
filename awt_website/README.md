# AWT Interactive Learning Platform

## Live Website
https://awt-lectures.vercel.app/

## Overview
AWT Interactive Learning Platform is a modern web-based learning system for Advanced Web Technologies students. It provides interactive lectures, practical labs, progress tracking, notifications, and separate Admin and Student portals.
